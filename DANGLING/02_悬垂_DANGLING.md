## S01 核心幻想与定位

**一句话**：一款胜利条件是**改变引用图拓扑**而非清零血量的即时战术 Roguelike。

| 项 | 内容 |
|---|---|
| 类型 | 即时战术 / Roguelike（实时，但可暂停规划） |
| 视角 | 节点图编辑器，上帝视角 |
| 单局结构 | 选数据结构（身体）→ 8–12 房间 → 中途一次"重构"迁移 → Boss |
| 核心资源 | 引用计数、`heap`、时间片、泄漏物 |
| 玩家动词 | `LINK` / `UNLINK` / `ALIAS` / `CAST` / `MOVE` |
| 胜利条件 | 引用归零（GC 擦除）／类型改写（CAST）／传统击杀（兜底） |
| 开发难度 | 中 ｜ 原型 2 周 |

**核心幻想**（B 稿原句）：你操作的不是物体，是引用。击杀 = 让引用计数归零。

### 设计支柱

- **P1｜世界只有两类东西：对象，和指向对象的引用。**
- **P2｜击杀 = 让引用计数归零，或把类型强转成无害。**
- **P3｜泄漏物是资源，不是惩罚。**

### 反模式禁令

- ❌ 禁止给对象设置独立 HP 条作为主要胜利路径。
- ❌ 禁止让"直接伤害"成为最高效解法（必须让剪引用更快）。

### 差异化与同类核验

检索到的 **memcon**（iOS 教学游戏）已经把 ARC 语义可视化：强／弱／无主引用、循环引用、僵尸对象、`EXC_BAD_ACCESS`，并整合 GCD 的队列／调度组／信号量做死锁与竞态关卡。

- memcon 的定位是"概念可视化 + 实操反馈 + 即时评估"的学习工具，**反馈是"对/错"**；
- 本作**反馈是"赚/亏"**，且全程处于实时对抗压力下，还有 Build 构建与随机局；
- 这就是本作与 memcon 唯一、但决定性的分界线。

**四款中的位置**：UI 范式成熟（节点图 + 剪边），与《渐进记号》并列建议首做。风险不在概念，在"实时中连线是否来得及"（见 S10）。

## S02 核心循环

```text
【30 秒】扫描引用图 → 找枢纽节点 → LINK/UNLINK 改拓扑 → 等 GC 擦除
【3 分钟】遭遇 Cycler(循环引用) → 找 weak 破环点 → 处理泄漏累积 → 房间清空
【一局】选数据结构(身体) → 8~12 房间 → 中途一次"重构"迁移 → Boss
```

| 层 | 玩家在想什么 | 必须给出的反馈 |
|---|---|---|
| 30 秒 | "剪哪条边能让一片归零？" | 剪断瞬间的级联回收必须可视化 |
| 3 分钟 | "这个环从哪破？" | 强／弱边可区分，weak 破环点可定位 |
| 一局 | "我这副身体（数据结构）扛不扛得住？" | 迁移的真空期是压力事件，不是菜单 |

〔待定〕GC 停顿是全局节奏事件，会同时冻结玩家与敌人；它必须可预判（有倒计时或固定周期），否则 30 秒层会变成"等运气"。

## S03 规则与系统规格（可执行）

### 3.1 世界模型

```text
ObjectGraph {
  nodes: [ {id, type, refcount, slot, flags} ]
  edges: [ {from, to, kind: STRONG|WEAK|UNOWNED|DANGLING} ]
}
```

`refcount` = 入边中 **STRONG** 的数量（WEAK / UNOWNED 不计入；DANGLING 指向已释放槽）。

### 3.2 五个玩家工具

| 工具 | 语义 | 成本 |
|---|---|---|
| `LINK` | 创建一条引用（refcount++） | 1 时间片 |
| `UNLINK` | 删除一条引用（refcount--） | 1 时间片 |
| `ALIAS` | 让 A 与 B 指向同一对象 | 2 时间片 + heap |
| `CAST` | 类型强转（改变对象的行为规则） | 3 时间片，可能触发 UB |
| `MOVE` | 基址 + 整数偏移 | 0，但**越界风险** |

### 3.3 胜利判定

```text
if refcount(target) == 0  → GC 擦除（无伤害、无动画、直接消失）
if CAST(target) == null   → segfault 眩晕 N tick [假设 N=3]
if HP(target) == 0        → 传统击杀（成本最高，作为兜底）
```

**三条路径的成本必须严格递增**，否则 P2 崩塌。

〔修正／合并〕B 稿另列了一条"空解引用 → 置空 → 敌人 segfault 无法行动；自己被置空 = 掉命"。它与 `CAST(target)==null` 是同一结果的不同入口，本稿合并为一条：**让目标的引用变为 null（强转成空类型或直接置空）→ 目标 segfault → 眩晕 N tick。** 眩晕与"直接消失"的强弱关系需实测。

〔逻辑缺口〕眩晕并不消灭目标，把它列为"胜利路径"与原文自洽性不足：三条路实际只有两条能直接移除敌人。需二选一定义——**A. 眩晕期间可被推入 GC**（拓扑解法仍为主）；**B. 眩晕 = 战术性移除**（不再补刀）。否则"成本严格递增"的三条路不成立。

### 3.4 核心机制

| 机制 | CS 依据 | 玩家动词 | 效果 | 失败态 |
|---|---|---|---|---|
| 别名 Aliasing | 两个指针指向同一块内存 | 连线 | 两对象共享伤害／增益／状态（双向同步） | debuff 也共享 |
| GC 擦除 | 引用计数归零即回收 | 剪断入边 | 入度归零者被回收（无伤害、无动画、直接消失） | — |
| GC 停顿 | stop-the-world | 预判 | 全场冻结 `T` 秒 `[假设 T=1.5]` | 在停顿里被围死 |
| UAF | 释放后槽位被重新分配 | 保留悬垂指针 | 该槽上的下一个新对象被指针吸附 → 获得其控制权 | 指针指向随机数据 |
| 内存泄漏 | 失去引用但未回收 | 放任 | 不可选中／不可攻击／不可回收，但依然存在、依然挡路；对敌人**不可见** | 累积超阈值 → OOM → 本局结束 |
| 指针运算 | 基址 + 整数偏移 | `MOVE` | off-by-one 可读写竞技场边界外一格，即关卡元数据（刷新表、Boss 血条） | 越界触发 UB／差一格就崩 |

各机制的细节：

1. **别名 Aliasing**：alias 后所有伤害／增益／状态**双向同步**。
   - 炸弹 ↔ Boss：一次引爆等于击杀；
   - 五个小怪串成别名链：一击全灭，但 debuff 也全吃；
   - **自己 ↔ Boss**：共享血条，配吸血是最强 build，也是最脆的。
2. **GC 擦除**：正确打法是**先孤立，再回收**——不是"打死"，是"让它没人引用"。
3. **GC 停顿**：周期性 stop-the-world，`T=1.5s` `[假设，需验证]`。必须预判，可围绕它安排大招。
4. **UAF**：被回收的槽位会被重新分配。若**故意保留悬垂指针**指向该槽，新对象生成时指针自动吸附 → **你获得对新敌人的控制权**。这是深渊技巧，也是高阶 build 的核心。
5. **内存泄漏**：泄漏节点不可选中、不可攻击、不可回收，但依然存在、依然挡路；且对敌人**不可见** → 完美掩体。泄漏累积超阈值 → OOM。
6. **指针运算与 off-by-one**：`MOVE` 是基址加整数。差一格就能读写**竞技场边界之外的那一格**，也就是关卡自己的元数据（刷新表、Boss 血条）。

〔修正〕A 稿在机制 6 写着"越界触发 UB 事件（跨文件联动至《类型良好》）"。《类型良好》不在四款之列，疑为旧稿残留。本稿改为"跨作联动〔待定〕"，交给 S10 处理，不把不存在的作品写进依赖。

## S04 涌现与反应

| # | 组合 | 效果 |
|---|---|---|
| R1 | `ALIAS` + 自伤 | 伤害同步给 Boss → 最强也最脆 |
| R2 | `UNLINK` × k → refcount=0 | 敌人**当场消失**，无战斗过程 |
| R3 | 泄漏节点 + 敌人视野 | 泄漏物对敌人不可见 → 免费掩体网络 |
| R4 | 悬垂指针 + 新分配 | 劫持刷新（UAF） |
| R5 | `CAST(float→int)` | 敌人失去小数部分（抖动／闪避消失），变得完全可预测；被截掉的比特**飞溅成弹幕伤害** |
| R6 | `CAST(any→pointer)` | 静态障碍物变为可移动 |
| R7 | off-by-one `MOVE` | 读写关卡元数据（速通路线） |
| R8 | 强引用循环 + WEAK 破环 | Cycler 类敌人唯一的解法 |

### 设计内的三条因果链

1. **孤立 → 回收**：R2 的前置是剪掉所有入边，所以"打谁"变成"先孤立谁"。这直接生成了"先切枢纽、再收尾"的战术层。
2. **共享即双刃**：R1 与"五小怪别名链"是同一个机制的两端——串得越长，一击越爽，吃 debuff 也越狠。
3. **垃圾是地形**：R3 把"失败"（泄漏）变成地图资源，这是 P3 的唯一硬支撑；若泄漏变成纯惩罚，P3 就空了。

〔待定〕原稿要求反应表至少 3 条"设计者未预料但允许"的组合。候选观察点：R5×R1（把 Boss 转成 int 后别名共享，小数部分还会不会飞溅）、R4×R2（先批量回收再劫持，能否一次控制多个刷新位）、R7×R8（用越界指针直接改写 Boss 的引用计数，是否该封）。

## S05 敌人与 Boss

| 敌人 | 特性 | 解法 |
|---|---|---|
| **Sentinel** | 引用枢纽，持有大量入边 | 剪断它 → 级联回收一片 |
| **Cycler** | 主动制造强引用循环，使自己永不归零 | 必须用 WEAK 引用破环 |
| **Allocator** | 不断申请新节点抬高 n | 跨作联动：给《渐进记号》喂 n |
| **Zombie** | 已被回收但仍有指针指向 | 读它得到脏数据 → 可用于 UAF 劫持 |
| **GC Boss** | 主动触发 stop-the-world | 在冻结窗口内完成拓扑改造 |

敌人设计的共同原则：**敌人不是血量单位，是引用图上的结构**。所以"击杀"的动作永远是改图，不是输出。

## S06 肉鸽结构

### 6.1 随机源：数据结构即身体

开局选定，**它决定你的移动方式、脆弱点和灾难类型**：

| 结构 | 优势 | 劣势 | 特有灾难 |
|---|---|---|---|
| **链表** | 插入 O(1)，可瞬移到任意已访问节点 | 遍历 O(n)，极脆 | 断链 |
| **数组** | 索引 O(1)，站桩高血 | 扩容昂贵 | 扩容时全场震动 |
| **哈希表** | 查找 O(1) | 冲突引发随机混沌事件 | 负载因子超阈值触发 **rehash → 整个战场重新洗牌**（可预测的定时灾难，围绕它安排大招）`[假设 0.75]` |
| **树／图** | 可范围失效（切断子树） | 失衡退化为链表 | 退化 |

### 6.2 局内成长

**迁移数据结构**：链表 → 树 是一次昂贵的"重构"，中途有真空期（旧的失效、新的未成形）。这是本作的"换 build"时刻。

### 6.3 局外 meta

〔待定〕原稿只写"数据结构即身体"与局内迁移，未定义局外解锁。可选方向：解锁新结构／新工具（`CAST`、`MOVE`）／初始引用布局。**不要**做成数值成长，否则违反 P2 的成本递增。

## S07 界面与交互

**不是动作游戏。** 节点图编辑器 + 拖拽连线 + 暂停规划：

| 要素 | 设计 |
|---|---|
| 战场 | 一张实时变化的**有向图** |
| 视觉语言 | 节点 = 几何体；边 = 发光线缆；`refcount` = 节点上的环数 |
| 主要输入 | **拖拽**（拉线／剪线），不是移动 |
| 时间 | 可暂停规划；暂停是否限量〔待定〕 |

〔待定〕三种边（STRONG / WEAK / UNOWNED）必须在同屏可区分，否则"破环"无从谈起。建议用颜色 + 线型双编码，不单靠颜色。

## S08 技术实现〔推导〕

原稿未给本节。以下为按机制推导的约束，需程序确认：

1. **图与计数**：`refcount` 增量维护（每条边 O(1)），不做全图重算；回收用队列级联，避免递归爆栈（本作自己就在讲栈）。
2. **确定性**：GC 停顿、rehash、刷新表都必须是确定性时间轴，否则"预判"不成立，回放也做不了。
3. **越界沙箱**：`MOVE` 越界读写的是"关卡元数据"，必须显式建模成一块可访问区域，而不是真让程序越界。
4. **输入预算**：拖拽在实时下的判定窗口要先定（例如 200ms 内完成一条边），这直接决定 S10 的"暂停规划"是否必须。
5. **操作日志**：所有 LINK/UNLINK/ALIAS 可回放，便于调 bug 与做"拓扑回放"评分。

## S09 里程碑与验证

| 阶段 | 内容 | 周期 | 判据 |
|---|---|---|---|
| M1 | 节点图 + 剪边触发 GC | 2 周 | 玩家能看懂"剪断 = 消失" |
| M2 | 别名共享 | 1 周 | 玩家主动串联（含自残式） |
| M3 | UAF 劫持 | 3 周 | 最难做对，单独验 |
| MVP | 10 个节点，2 个工具（`LINK` / `UNLINK`），1 个 Sentinel，无 GC 停顿、无 UAF | 接 M1 | 循环闭合 |

**成功判据**：玩家在 3 分钟内发现"剪断入边比反复攻击更快"。

**失败即砍**：

- 若玩家只用 `ALIAS` + 炸弹 → GC 路径不够诱人 → **砍掉直接伤害技能**，逼迫拓扑解法。
- 若 UAF 在测试中 0 次被自发发现 → 它不是机制而是彩蛋 → **砍掉，改为显式"劫持"按钮**。
- 若 M2 测试中玩家来不及连线 → 改为"暂停规划 + 实时执行"（Into the Breach 式），**不要**改成自动瞄准。

**内容管线（原 G09）**：敌人/数据结构/关卡都是数据表——`{节点数, 边类型分布, 特殊规则, 灾难周期}`，关卡设计师不写代码。
