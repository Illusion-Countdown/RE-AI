## 1. 核心机制

### 1.1 引用图

- 世界由 `Node` 和 `Edge` 组成。
- `refcount` 只统计 **STRONG 入边**。
- STRONG 入边归零 → 对象被 GC 擦除。
- GC 会递归处理该对象的出边，形成级联。
- WEAK 不计入 refcount。
- 玩家自己的 HOLD 边（LINK 敌人）不计入 refcount，不会把敌人锚在内存里。
- ALIAS 组共享血池，伤害和死亡同步。
- 部分敌人带析构器：死亡时对周围造成伤害。
- 快捷键 `G` 可免费立即 GC（有规则/次数限制）。

### 1.2 卡牌与内存

- 卡牌是网格里的实体，占格数由 `shape` 决定。
- 网格内所有卡 = 本局抽牌池。
- 未入网格的卡进入 **BENCH**，不参与战斗。
- 手牌：**3 张，无备用槽、无溢出槽**。
- 初始抽 3 张；每使用 1 张立刻抽 1 张；牌堆抽空后无法继续抽。
- 每张卡每房最多回收一次：第一次使用后随机放回牌堆，第二次使用后本房耗尽。
- 下一房重新计算：手牌、回收次数、耗尽状态全部重置。
- 卡牌可 `++` 升级；当前升级免费，通过拖拽同名基础卡完成。

### 1.3 画质

```text
画质 = 100
     - 50 × (已占用格 + 坏死格) / 总格
     - 50 × 工作内存消耗 / 空闲格
```

- 画质受工作内存和坏死格影响；不再有洗回惩罚。
- 四个档位：清晰 / 轻微降采样 / 低分辨率 / 像素崩溃。
- 最低档世界只保留约 11% 像素量；HUD 和文字保持清晰。
- 画质过低会持续扣血，归零即失败。

### 1.4 工作内存

- CUT 消耗 1 工作内存。
- 高费卡消耗更多工作内存。
- 工作内存同时参与画质公式，所以“放技能”本身会降低画质。
- 空闲格不足时，重型卡会迅速把画质压垮。

### 3.1 稀有度分布

| 稀有度 | 数量 | 卡牌 |
|---|---:|---|
| 基础 | 3 | CUT / LINK / WEAK |
| 进阶 | 8 | CLIP / SWEEP / WEAKEN / ALIAS / VOID / TRUNC / DELAY / DOWN |

### 3.2 完整卡表

| Key | 名称 | 形状 | 目标 | 工作内存 | 稀有度 | 效果 |
|---|---|---|---:|---:|---:|---|
| `CUT` | 单剪 | 1×2 | 边 | 1 | 基础 | 按住左键划过引用线，剪断划到的第一条边；引用归零触发 GC |
| `LINK` | 硬链 | 1×2 | 双目标 | 0 | 基础 | 从 A 拖到 B 建立强引用；从自己拖向敌人时敌人停火并分摊 15%/条，上限 45% |
| `WEAK` | 弱观测 | 1×1 | 双目标 | 0 | 基础 | 目标受到伤害 +35%，对玩家伤害 -35%；不计 refcount |
| `CLIP` | 连剪 | 1×3 | 单目标 | 0 | 进阶 | 点一个对象，剪断它的全部入边 |
| `SWEEP` | 横扫 | 2×1 | 区域 | 0 | 进阶 | 鼠标处半径 150 内最多剪断 3 条边 |
| `WEAKEN` | 弱化 | 1×1 | 边 | 0 | 进阶 | 把一条强引用降级为弱引用，refcount -1 |
| `ALIAS` | 别名 | 2×2 | 双目标 | 2 | 进阶 | 6 秒内两个对象共享血池，伤害/死亡同步 |
| `VOID` | 空转 | 2×2 | 单目标 | 2 | 进阶 | 剥掉析构器，眩晕 2 秒，出边悬空 2 秒 |
| `TRUNC` | 截断 | 2×2 | 单目标 | 2 | 进阶 | 剥掉析构器，禁止重建，对周围造成 34 伤害 |
| `DELAY` | 延迟剪 | 1×1 | 边 | 0 | 进阶 | 3 秒后自动剪断这条边，可提前离场 |
| `REFLECT` | 反射剪 | 1×2 | 边 | 0 | 稀有 | 剪断一条边，把目标的析构伤害反射给最近敌人 |
| `STEAL` | 引用窃取 | 1×2 | 边 | 1 | 稀有 | 剪断敌方边，并把这条引用收归自己 |
| `COMPRESS` | 压缩 | 1×2 | 自身 | 0 | 稀有 | 工作内存拉到 90%，8 秒内伤害 +30%，之后双倍回落 |
| `ECC` | 纠错码 | 1×1 | 坏死格 | 0 | 稀有 | 修复 1 个坏死格；`++` 修复 2 个 |
| `LOSSY` | 有损爆发 | 2×3 | 区域 | 3 | 稀有 | 半径 180 内 80 伤害；永久毁掉 2 个空闲格 |
| `DOWN` | 降采样 | 2×2 | 区域 | 2 | 进阶 | 敌人和子弹减速 30%，持续 5 秒；画质上限 -20 |

### 3.3 卡牌定位

- **CUT / CLIP / SWEEP / WEAKEN / DELAY / REFLECT / STEAL**：拓扑解，处理引用结构。
- **LINK / WEAK / ALIAS**：关系和承伤，改变敌我引用。
- **VOID / TRUNC**：拆析构器和类型免疫前置。
- **COMPRESS / DOWN / LOSSY**：用画质换输出/控场。
- **ECC**：修复坏死格，长线续航。
