# 07 · 备选机制库（**当前版本不启用**）

> **这份文件里的所有机制，现在的游戏都不使用。**
> 保留完整原始设计，是为了两件事：**① 以后想加回来有据可查 ② 知道当初为什么砍。**
>
> **给协作者的话：看到本文件里的东西，不要实现它。**
> 要启用任何一条，必须同时改 `01` `02` `06` 三处，并在这里标记"已启用"。

---

## 1. 环境选择：接受 / 覆写 / 隔离

**状态：❌ 已排除。现在环境是随机的，玩家不能改。**

### 之前的完整效果

每个节点开始掷出环境后，玩家有三个选项：

| 选项 | 花费 | 结果 |
|---|---|---|
| **接受** | 免费 | 环境对**双方**生效 |
| **覆写 Override** | **2 算力** | 环境只对**你**生效，敌人回到中立 |
| **隔离 Sandbox** | **1 算力 + 2 显存** | 环境对**双方**都不生效，你也拿不到加成 |

精英和 Boss 锁定环境，不能覆写。

### 为什么砍

它是**每节点一次的决策**，但它需要玩家理解 8 种语言的规则才能判断"该不该覆写"。
**在玩家还没搞懂语言是什么的时候，先给他一个关于语言的决策 = 劝退。**

### 现在怎么做

```
环境随机掷出 → 直接生效（双方）→ 你不能改
你能做的只有：看到它，然后调整摆位
```

> **信息还是免费的，选择权收回了。**

### 怎么恢复

在 `02` §7 加回"三个选项"表，在 `06` 加回两个常量（覆写 2 算力 / 隔离 1+2）。

## 2. 多 AI 控制（最多 3 个）

**状态：❌ 已排除。现在整局只有 1 个 AI。**

### 之前的完整效果

| 项 | 规则 |
|---|---|
| 数量 | 开局 1 个，事件招募到 **最多 3 个** |
| 管辖权 | 每个 AI 盖一块连通区域（上下文窗口 6~20 格） |
| **共管** | 两个 AI 可以盖同一格，加成叠加（第二个按 70%） |
| **对齐摩擦** | 共管格每波 +1 层；3 层 25% 卡住，5 层暴走 |
| **羁绊** | 1 个阵营羁绊（同阵营 ×2）+ 1 个关系羁绊（特定组合） |
| 大招 | 每个 AI 各一个，各自充能 |

### 为什么砍

**它是系统复杂度爆炸的主因。**

```
多 AI → 需要管辖权 → 需要共管 → 需要摩擦 → 需要羁绊 → 需要平衡 3 个大招
```

**一次砍掉，连带砍掉 3 个系统**（共管、摩擦、羁绊）。

而且玩家在原设计里要同时管 3 块地、3 根充能条、3 套进阶——**这已经是一个独立游戏的工作量。**

### 现在怎么做（**这是这次砍得最值的一刀**）

```
整局只有 1 个 AI
它只能管辖 N 格（DeepSeek 12 / Gemini 20 / Mistral 6 …）
你有 6~8 个棋子，但只有一部分在辖区内 → 吃加成
```

**于是"管辖权"从"分配任务"变成了"取舍"：**

| 你的棋子 | 在辖区内 | 在辖区外 |
|---|---|---|
| 输出最高的 3 个 | ✅ 吃满加成 | — |
| 当墙的 2 个 | — | ❌ 只吃区域加成 |
| 辅助 | — | ❌ |

> **"我要把哪几个棋子放进 AI 的视野里"——**
> **这句话一个新手能听懂，而"三个 AI 怎么叠"他听不懂。**

### 怎么恢复

`01` §2.3 的多 AI 表、`02` §6 的共管与进阶、`06` §9 的窗口表都要回来。
`02` §15.1 的"招募事件"也要回来。

## 3. 技术债

**状态：✅ 已恢复（v0.4.12 重新加入游戏）。**

### 之前的完整效果

每 revert 一次，技术债 +1（有 `update` 钩子则 +2）：

| 技术债 | 后果 |
|---|---|
| 1–2 | 敌人 HP **+10% / 层** |
| **3–4** | **所有棋子启动延迟 +0.5 秒** |
| 5 | 精英 / Boss **必出 AI 型敌人** |
| 6+ | Boss **多一个阶段** |

唯一还债方式：击败孤儿节点的**残影**（-1 层）。

### 设计初衷

> **"你欠的债，最后都变成编译时间。"**
> 这是 3.2 那一版最漂亮的一句话——revert 不是免费的，它让你整个阵容变慢。

### 为什么砍

**它是"迟到"的机制。**

玩家要到第 3~4 层才会感觉到"我的棋子怎么变慢了"，
**但那时他要么已经赢了，要么已经放弃了。**

> **一个玩家感受不到的惩罚，等于不存在；一个让他莫名变慢的惩罚，等于 bug。**

### 风险（**必须知道**）

**砍掉技术债后，revert 只剩下"花 1 个额度"这一个代价。**

可能导致的后果：

```
revert 变得太便宜 → 玩家反复回退刷开局 → 一局变成"抽到好牌为止"
```

**如果实测出现这个现象，两条补法：**

| 补法 | 做法 |
|---|---|
| **A** | revert 改成 **2 额度**（变贵，但容易理解） |
| **B** | 恢复技术债，但**只保留 1–2 层那条**（敌人 HP +10%/层），砍掉"启动延迟" |

> **B 更接近原设计精神：让债影响敌人，而不是影响你的手感。**

### 怎么恢复

在 `02` §13.7 加回技术债表，在 `06` §9 加回 4 条阈值。
残影还债的逻辑在 `02` §13.8，**那个没砍，还在**。

## 4. 对齐摩擦

**状态：❌ 已排除。它依赖多 AI，多 AI 砍了它自然消失。**

### 之前的完整效果

两个 AI 盖住同一格时：

| 项 | 规则 |
|---|---|
| 加成 | 两个都生效，第二个按 **70%** |
| **摩擦** | 每波结束，重叠格 **+1 层**（上限 5，**不衰减**） |
| 摩擦 3 层 | 该格棋子 **25% 概率卡住**（跳过行动） |
| 摩擦 5 层 | 该格棋子**暴走**：攻击随机目标，持续到节点结束 |
| 清除 | 只有 `flush` 卡能清（-3 层），或者把管辖权挪开 |

### 设计初衷

> **现实里两个模型处理同一段代码，要么更快，要么互相打架。**
> 叠是最强的，也是唯一会让你自己人打自己人的。

### 为什么砍

**它存在的唯一前提是"两个 AI 盖同一格"。**
单 AI 之后这个前提不存在了——**它自动失效，不需要额外处理。**

### 怎么恢复

**必须和多 AI 一起恢复。** 单独恢复没有意义。

## 5. 连带失效：羁绊系统（**需要你确认**）

**状态：❌ 已确认移入备选（v0.4.12）。**

羁绊的全部设计都是"队伍里有 2~3 个特定 AI"：

| 羁绊 | 需要 |
|---|---|
| 开源共识 / 闭源算力 | 同阵营 ×2 |
| 中美对撞 / 安全对齐 / 国产双雄 … | 特定两个 AI |

**单 AI 之后，没有任何一条能触发。**

### 三个选择

| 方案 | 说明 |
|---|---|
| **A（我建议）** | **整体移入备选**，和多 AI 一起封存。等单 AI 版本跑通了再说 |
| B | 改成"AI 与**棋子标签**的羁绊"——比如 DeepSeek ×2 个「搜索」标签棋子 → 触发 |
| C | 保留数据，但游戏里不显示（等于没有） |

**已采用 A：整体封存。** 理由：现在要做的是减法，不是把一个失效系统改装成另一个系统。
